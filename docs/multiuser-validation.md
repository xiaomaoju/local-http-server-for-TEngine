## 实际运行

- 桌面本地：从测试 Bundles 目录选择版本、同步、启动 HTTP 服务；读取实际资源内容，随后停止服务。
- 桌面远程：账号登录、原生目录选择、完整上传 `native-r1`、手动发布；再增量上传 `native-r2`。确认上传不改变当前发布，手动切换后下载新版本号和复用文件内容。
- 桌面重启：保留地址与用户名，密码为空，需要重新登录。
- macOS 键盘：设置侧栏内 Shift+Tab 循环到最后一个按钮，Escape 关闭后焦点返回“项目设置”。
- Docker：替换容器并复用测试数据目录，验证修改后的密码、项目 UUID、发布状态、文件与审计记录仍在，初始化变量不会重置已有密码。
- HTTPS：使用独立测试 CA 校验连接，验证登录 Cookie 包含 Secure、HttpOnly、SameSite，管理响应禁止缓存，公开资源下载正常。
- 用户生命周期：在测试容器中补查禁用后拒绝登录、恢复后可登录、退出后旧会话失效。

## 视觉与可访问性

深浅主题均检查 960×700 和 800×600 实际截图；960×700 显示完整主操作区与至少 8 条版本记录，800×600 无页面级横向溢出。正文、辅助文字、主按钮及成功/警告/错误文字的核心配色组合均达到 WCAG 4.5:1；最低测得 5.37:1。禁用控件不按正文标准计算。

设计与可访问性做了两份独立源码审查，已修正上下文切换、上传提示残留、本地错误反馈、原生表单语义、触屏目标与日志颜色等问题。此记录不代表完整 WCAG 认证。

本机截图位于 `Cache/tests/workbench-{dark,light}-{960,800}.png`，命令输出在 `Cache/debug/multiuser/`。缓存不进入版本控制，可按开发指南重新生成。
