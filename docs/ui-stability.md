# 交互稳定性修复

2026-09-29，针对已部署后台的周期性闪烁、创建项目弹窗意外关闭，以及相关操作流程进行检查。生产入口仅做只读诊断；所有写操作验证使用隔离测试环境。

## 原因与行为

- 实时连接经过反向代理时，后端收到的请求缺少 WebSocket Upgrade 头。旧客户端每次重连都会触发前台刷新，导致加载状态反复出现；未选中项目时还会清空打开的弹窗。
- 实时连接现在独立重试，失败时按 2–30 秒退避，每 15 秒静默同步已有内容。服务端发送心跳，减少空闲连接断开。代理类型不作为客户端分支；群晖与 Nginx 各自的入口配置见 [部署说明](multiuser.md#两种反向代理部署)。
- 所有共用弹窗不再响应空白处或遮罩点击关闭。关闭按钮、取消和 Escape 保留；有未保存输入时确认放弃，保存过程中锁定表单。首次强制改密仍允许输入，只禁止关闭。
- 配置冲突采用字段合并：未改字段读取新值，同字段冲突必须明确选择保留哪一方，避免刷新修订号后覆盖其他成员的修改。
- 发布、删除、下载开关和所有权操作固定确认时的对象与修订号。后台同步改变当前版本后，已打开的确认框不会误操作另一个版本。
- 删除分页最后一条记录后回到有效页；写入成功但随后刷新失败时，在页面明确说明已保存与读取失败，避免用户重复提交。
- 本地同步忽略切换项目前发出的迟到响应；本地设置保存期间不能取消或修改。运行中的服务需要先停止才能变更配置和下载开关，保证界面与实际服务一致。
- 用户管理保留未保存输入，提交时锁定字段；读取失败后的成功重试清除旧错误。

## 部署边界

源码修复需要重新构建和部署应用才能影响线上页面；代理头配置需要在对应的 DSM 或 Nginx 中应用。此次没有改动用户的生产容器、反向代理规则或生产数据。群晖配置步骤依据官方文档，未在用户 DSM 中实际保存验证。

此次桌面回归验证的是 Vue 交互与命令参数，未重新执行原生 Tauri 打包或真实文件同步；原生运行的前一轮记录见 [多用户改造验证记录](multiuser-validation.md)。Nginx 本次检查配置语法，未替用户执行服务器重载。
