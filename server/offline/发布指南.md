# 一键安装 / 更新

1. 解压安装包到 Downloads 等临时目录。
2. 检查 `install.env` 的 `INSTANCE_DIR`，默认 `/volume3/docker/TEngineHttpV2`，它必须与安装包目录分开。
3. 在安装包目录运行 `sudo sh deploy.sh`。

首次安装使用 `settings.env.example` 创建实例配置，默认初始化用户名 **children**。真实配置和密码在实例目录的 `settings.env` 中。

已有部署会提示：

```text
是否覆盖更新？Y=覆盖，N=忽略 [Y/N，默认 N]：
```

Y 更新前备份，保留配置、账号与资源；N 或回车不部署。更新不会重新初始化用户。

**从旧版切换：** 旧数据若还在 Downloads 的解压目录，请将新包解压到另一个目录，保留旧目录。脚本会读取原容器挂载，停服备份后复制数据到独立实例目录。迁移成功后，删除旧安装目录不会影响新实例。

部署成功后可删除安装包。**不要删除 `/volume3/docker/TEngineHttpV2` 实例目录。** 已有实例缺库时会停止。若旧测试目录已删、只剩残留容器，且新实例目录没有配置和数据，脚本会提供单独的重新安装 Y/N 确认；默认 N，选择 Y 创建全新账号与数据库。

群晖使用 DSM 反向代理并添加 WebSocket 标头；服务器使用包内 Nginx 示例。默认转发到本机 8083。端口只配置 `PORT=8083`，宿主机映射、容器监听和健康检查保持一致；更改端口时同步修改反向代理的目的地端口。详细配置、批量发布与备份见 `README-部署说明.md`。
