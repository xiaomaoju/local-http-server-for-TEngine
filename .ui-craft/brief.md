# TEngine 资源工作台

## Product and audience
资源上传、发布和共享管理工具，服务于开发者与没有技术背景的策划。中文界面；Web 后台与桌面本地/远程模式采用相同视觉语言。

## Workflow
选择项目 → 选择项目版本和平台 → 上传资源 → 确认发布 → 复制地址。上传成功不代表发布成功。系统管理员管理用户，项目所有者管理分享，成员可以操作资源。

## Design principles
深色默认，可切浅色；中性石墨灰和单一青绿强调色。以表格为主，主操作和发布状态始终可见。低频设置进入侧栏。错误提供可执行的恢复路径，保留用户输入。

## Constraints
沿用 Vue 3 和 CSS。默认桌面窗口 960×700，最小 800×600。页面 padding 12px、小窗口 8px，控件高 32px，表格行高 36px。触屏目标至少 44px。正文 13px、辅助 12px，不能用小字补救溢出。

## Acceptance
960×700 首屏显示全部主要操作及至少八条版本记录；800×600 无页面横向溢出；表单有标签、错误提示和键盘焦点；模态关闭恢复焦点；加载、失败、冲突及无权限状态真实。两种主题均需实际截图核对。

底部日志默认展示操作日志；高频资源访问、下载失败及 HTTP 状态放在独立“资源请求”页签。两类独立保留、计数、清空和滚动，资源刷屏不能占用正常操作日志的条数、错误提示或阅读位置。

## Learned constraints
项目导航的类型标记只显示 Ⓐ（APP更新）、Ⓑ（Bundle）、Ⓕ（文件），节省标签宽度；悬停和无障碍名称保留完整类型名，使用说明解释符号含义。
用户明确要求紧凑：能两行完成就不拆三行；不放无关图表、欢迎大卡片或装饰。文件列表、版本与发布状态优先于设置。保留两层版本概念，解释术语。用户指令优先于技能中的通用 dashboard 图表建议。

表单弹窗与设置侧栏不能因为点击内容空白或遮罩而关闭；仅通过明确关闭按钮、取消或 Escape 退出，有未保存输入时需确认。后台同步和连接重试不能替换已有内容、清空草稿或禁用正在编辑的字段。群晖与 Nginx 分别提供部署配置，客户端依据实际连接状态自动重连或定时同步，不绑定某一种代理。

保留已保存服务器列表及明确保存入口，方便切换多个服务器。项目、项目版本、平台使用连续的紧凑标签，新增入口直接可见；平台标签放在发布栏左侧，发布方式及说明靠右。项目列表整行可打开并显示版本名称，不以版本数量代替。平台多选必须有明确开关反馈。

平台与发布方式一行位于项目版本标签下方；当前发布版本、下载开关与复制地址一行紧随其后。构建目录自动记忆；打开上传窗口自动读取最新本地构建和服务器最近上传版本作为对比，保留手动切换及四类文件差异。长文件名需能辨认差异并完整查看、复制，允许按需换行。资源版本删除直接放在行内并保留确认。手动发布为默认值，自动发布只影响当前客户端，按账号、服务器、项目版本及平台分别保存；上传失败和发布失败必须明确区分。

所有常用操作在静止状态就能辨认：文字按钮使用柔和底色及淡描边，危险操作可用淡色底区分，避免满屏亮白边框。新增项目、版本、平台保留虚线；未选中的导航标签及服务器条目不加装饰描边，选中项才突出。输入框使用淡描边，键盘焦点保留清晰轮廓。互斥设置（发布方式、上传来源、工作模式、项目范围）使用带单选圆点的成组控件，外框和内部分隔保持克制；项目、版本、平台仍为导航标签。下载权限显示明确开关与开启/关闭文字。状态、数值和辅助说明不得套用操作按钮样式；重要版本号和上传结果靠字号、字重和位置形成层级。发布行只轻微着色，删除按钮始终保留在行内，禁用原因支持键盘读取。上传窗口提供“重新读取”，新构建完成后不必关闭重开。
